# Current Implementation Status

This matrix compares the runtime hardening target with the current implementation.
>
> User state directory note (2026-08-17): run state, memory, and the default
> MCP catalog resolve through the per-workspace user data contract
> (`<data_root>/workspaces/<storage_key>/`), while ProductStore is API-global at
> `<data_root>/product.sqlite`. CLI, API, embedded hosts, and migration tooling
> share the bootstrap resolver; explicit config overrides keep the
> historical semantics and project directories keep only trust-gated
> project configuration. `rove state paths` / `rove state migrate`
> (dry-run, apply, conflict policy, prune) are implemented with
> hash-based idempotency, prepared journals, transactional SQLite artifact-path
> rebasing, and copy-safe semantics. Desktop keeps its
> explicit state-dir injection. See
> [`STATE_LAYOUT_AND_MIGRATION.md`](../../STATE_LAYOUT_AND_MIGRATION.md).
