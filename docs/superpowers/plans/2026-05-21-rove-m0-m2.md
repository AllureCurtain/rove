# rove M0-M2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ship a compile-clean local-first agent runtime through M2: workspace detection, streaming model loop, tool execution, trace/report/state persistence, resume, and a basic planner.

**Architecture:** M0 fixes the bootstrap path and artifact identity. M1 makes state, tools, context, and resume first-class runtime services. M2 adds a persisted planner so longer tasks run as explicit steps instead of one opaque ReAct loop.

**Tech Stack:** Rust 1.95.0, tokio 1.52.3, reqwest 0.13.3, clap 4.6.1, serde 1.0.228, serde_json 1.0.149, thiserror 2.0.18, anyhow 1.0.102, chrono 0.4.44, ulid 1.2.1, tracing 0.1.44, tracing-subscriber 0.3.23, async-stream 0.3.6, async-trait 0.1.89, futures 0.3.32, tokio-stream 0.1.18, eventsource-stream 0.2.3, dotenvy 0.15.7.

**Version note:** verify the Rust release line against the official Rust blog and refresh crates against crates.io again before continuing implementation. On 2026-05-21 this workspace uses `rustc 1.95.0` through `rust-toolchain.toml` with `channel = "stable"`; the exact `1.95.0` toolchain pin was avoided locally because rustup component resolution was not reliable.

**Scope guard:** no API layer, no Web UI, no RAG, no MCP, no multi-agent, no desktop/browser automation in this plan.

async fn collect_events_with_request(engine: &Engine, req: RunRequest) -> Vec<StreamEvent> {

    futures::pin_mut!(stream);
    let mut events = Vec::new();
    while let Some(event) = stream.next().await {
        events.push(event);
    }
    events
}
